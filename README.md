# Cities - Branch `develop`

## Descripción
La rama `develop` contiene los últimos avances en el desarrollo de la aplicación **Cities**. Esta rama es el punto de integración para nuevas características, correcciones de errores y mejoras generales. Es el lugar donde se realizan todas las modificaciones antes de ser fusionadas en la rama `production`.

## Características y Mejoras en Desarrollo
Esta rama incluye las siguientes características y mejoras en desarrollo:

- **Integración de API de ciudades**: Conexión con fuentes de datos externas para obtener información sobre ciudades, como población, clima, puntos de interés, etc.
- **Base de datos de ciudades**: Implementación de un sistema para almacenar y gestionar información sobre ciudades de manera eficiente.
- **Interfaz de usuario**: Diseño y desarrollo de una interfaz visual que permite buscar y explorar ciudades.
- **Filtrado y búsqueda avanzada**: Implementación de filtros avanzados para explorar ciudades según criterios como población, ubicación geográfica, clima, etc.

## Pruebas y Validación
- **Pruebas unitarias**: Todas las nuevas funcionalidades estarán cubiertas con pruebas unitarias.
- **Pruebas de integración**: Los cambios en la base de datos y la API no afectarán en la integración de otros servicios.
- **Pruebas de rendimiento**: Búsqueda de ocio en distintas ciudades y la visualización de datos sean rápidas y escalables.

## Tareas Pendientes
- [ ] Completar la integración con la API externa de ciudades.
- [ ] Mejorar el rendimiento de las consultas a la base de datos.
- [ ] Añadir nuevas funcionalidades de búsqueda (por ejemplo, búsqueda por códigos postales).

## Notas Importantes
- **Desarrollo en curso**: Esta rama está en constante cambio, por lo que es posible que algunas funcionalidades no estén completas o presenten errores.
- **Sincronización con `production`**: Esta rama se mantendrá actualizada con los cambios de `production` para evitar conflictos de integración a medida que las nuevas funcionalidades se desarrollan.
