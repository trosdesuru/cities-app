# Onboarding Page

## Descripción
Esta funcionalidad introduce una nueva página de **Onboarding** en la aplicación, diseñada para guiar a los nuevos usuarios y mejorar su experiencia inicial.

## Características
- **Diseño moderno y responsivo.**
- **Animaciones suaves** para mejorar la experiencia de usuario.
- **Navegación intuitiva** con opción de omitir el Onboarding.
- **Integración con autenticación** (si aplica).

## ⚠️ Nota Importante

-  Esta aplicación está en fase BETA.
No introduzcas credenciales reales ni información sensible, ya que la seguridad de los datos no está completamente garantizada en esta versión.
